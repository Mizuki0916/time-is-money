# Time is Money — 4人のYouTuberを見なくても内容がわかるPWA

選定した4チャンネルの新着動画を自動で拾い、字幕をAIで要約して、**銘柄ごとに4人の見解を並べて**表示するアプリです。
トップには4人の話をまとめた「今日のポイント」が出て、**金のブタさん**が相場の空気に合わせて表情を変えます。
各銘柄には **終値・前日比・チャート状況・出来高・RSI** も一緒に出ます。
iPhoneのホーム画面に置いて、普通のアプリのように使えます。

対象チャンネル（`scripts/config.json` で変更できます）

| | チャンネル | 略号 |
|---|---|---|
| 1 | Trader's Lab | TL |
| 2 | トレーダーTOMO | TM |
| 3 | Sho's投資情報局 | SH |
| 4 | ぺこ株 | PK |

## 全体の流れ

```
自宅のWindows PC（1時間おきに自動実行）
   YouTube RSS で新着チェック（APIキー不要）
        ↓
   字幕を取得（youtube-transcript-api → 弾かれたら yt-dlp／元言語の自動字幕を優先）
        ↓
   AIで要約 → 銘柄・スタンス・目標株価・理由を抽出
        ↓
   4人の要約をまとめて「今日のポイント」を作成
        ↓
   Yahoo Finance から日足と1分足を取得 → 出来高・RSI・移動平均・価格帯別出来高を計算
        ↓
   docs/data/*.json を更新 → GitHub に push
        ↓
GitHub Pages（無料・HTTPS）
        ↓
iPhone の Safari →「ホーム画面に追加」
```

字幕の取得はクラウド（GitHub Actions等）のIPからだとYouTubeにブロックされるため、
**収集だけは自宅PCで動かします**。公開と閲覧はネット経由なので、PCの場所は関係ありません。

## セットアップ

### 手順1. フォルダを置く

このフォルダごと `C:\stock-pwa` に置いてください（日本語を含まないパスにするのが安全です）。

### 手順2. Gemini の API キーを取る

1. https://aistudio.google.com/apikey を開く
2. Googleアカウントでログイン →「Create API key」
3. 表示されたキーをコピー（`AIza...` で始まる文字列）

無料枠の範囲で1日数本の要約なら十分収まる見込みです。他社のキーを使いたい場合は末尾の「AIを差し替える」を参照。

### 手順3. セットアップを実行

PowerShell を開いて:

```powershell
cd C:\stock-pwa
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

途中でAPIキーを聞かれるので貼り付けてください。ライブラリの導入、`.env` の作成、
タスクスケジューラへの登録（1時間おき + ログオン時）まで自動で行います。

### 手順4. まず字幕が取れるか確認する

**AIは呼ばないので料金はかかりません。** 4チャンネルそれぞれで字幕が取れるかを確認します。

```powershell
.\.venv\Scripts\python.exe scripts\check_captions.py
```

- `○ 字幕あり` … そのチャンネルは要約できます
- `× この動画には字幕がありません` … その動画はスキップされ、アプリ上に理由が表示されます
- `× YouTubeにIPをブロックされました` … クラウドで実行しています。自宅PCで実行してください

### 手順4b. 株価が取れるか確認する

こちらもAIを呼ばないので無料です。

```powershell
.\.venv\Scripts\python.exe scripts\check_prices.py
```

`o トヨタ自動車（7203.T）: 2026-08-15 終値 2850円 +1.24% / RSI 58.2 中立 / …` のように出れば成功です。
取れないときは `--raw 7203` を付けて実行すると、実際に返ってきた応答の冒頭が見られます。
1件も取れない場合は時間をあけて再実行してください。株価が不要なら `config.json` の `enable_prices` を `false` にできます。

### 手順5. 初回の収集

いきなり全部処理するとAPI利用が読めないので、まず2本だけ試します。

```powershell
.\run.ps1 --limit 2
```

要約された銘柄名がコンソールに並べば成功です。問題なければ上限なしで:

```powershell
.\run.ps1
```

### 手順6. パソコンで見た目を確認

```powershell
.\.venv\Scripts\python.exe -m http.server 8000 --directory docs
```

ブラウザで http://localhost:8000 を開きます。

### 手順7. GitHub Pages で公開する

1. https://github.com/new でリポジトリを作る（名前は例: `stock-digest`、**Private でもOK**※）
2. PowerShell で:

```powershell
cd C:\stock-pwa
git init
git add .
git commit -m "初回"
git branch -M main
git remote add origin https://github.com/<あなたのID>/stock-digest.git
git push -u origin main
```

3. GitHub のリポジトリ画面 → **Settings** → **Pages**
   - Source: `Deploy from a branch`
   - Branch: `main` / フォルダ: **`/docs`** → Save
4. 1〜2分待つと `https://<あなたのID>.github.io/stock-digest/` で開けるようになります

※ Private リポジトリの GitHub Pages は有料プランが必要です。無料で使うなら Public にしてください。
公開されるのは要約データだけで、APIキーは `.env` に入っており `.gitignore` で除外されます。

### 手順8. 自動pushを有効にする

`.env` の `GIT_AUTO_PUSH=0` を `1` に変えると、収集のたびに自動で GitHub に push されます。

```
GIT_AUTO_PUSH=1
```

### 手順9. iPhone に入れる

1. Safari で公開URLを開く（Chromeでは追加できません）
2. 下の共有ボタン → **ホーム画面に追加**
3. アイコンができるので、そこから起動

以降は自動で更新されます。オフラインでも直前の内容は読めます。

## 普段の使い方

| やりたいこと | 操作 |
|---|---|
| 今の相場の流れをつかむ | トップの「今日のポイント」。4人の話に共通する話題と、チャートの着眼点が3つ出ます |
| 4人の見解を銘柄ごとに見る | 「銘柄で見る」タブ。カードをタップで展開 |
| 売られすぎ・買われすぎを探す | 「RSI30以下」「RSI70以上」チップ |
| 出来高が膨らんだ銘柄を探す | 「出来高急増」チップ（25日平均の1.5倍以上） |
| 移動平均や52週レンジを見る | カードを開くと株価パネルが出ます |
| チャートを見る | カードを開くと日足のローソク足＋出来高＋移動平均。3か月／6か月を切替可 |
| 各日の四本値を見る | チャートを指でなぞる（PCはマウスを乗せる）と、その日の始値・高値・安値・終値・出来高が出ます |
| どの値段で売買されているか見る | チャートの下の「価格帯別出来高」。最も商いが多い価格帯と、出来高の7割が収まる範囲が出ます |
| 誰かが言ったその場面を確認 | 各見解の「▶ 12:34 から」を押すとYouTubeの該当位置が開く |
| 意見が割れている銘柄だけ見る | 「意見が割れている」チップ |
| 特定の人の話だけ見る | 下段の投稿者チップ |
| 動画単位で追う | 「動画で見る」タブ |
| 色に頼らず一覧で見る | 右上の「表」ボタン |

コンセンサス表示の4マスは**左から config.json の順に固定**で、
色がスタンス（<span>赤=強気 / 青=弱気 / グレー=中立 / 点線=言及なし</span>）、
文字が投稿者の略号です。

## コマンド一覧

すべて `C:\stock-pwa` で実行します。

```powershell
.\run.ps1                              # 新着を処理（タスクスケジューラと同じ動作）
.\run.ps1 --force                      # 制限の待機中でも強制的に試す
.\run.ps1 --digest                     # 新着が無くても「今日のポイント」を作り直す
.\run.ps1 --limit 3                    # 今回は3本まで
.\run.ps1 --dry-run                    # AIを呼ばず、対象と字幕の有無だけ確認
.\run.ps1 --video dQw4w9WgXcQ          # 特定の動画だけやり直す
.\run.ps1 --rebuild                    # 要約はせずJSONだけ作り直す
.\run.ps1 --refresh-prices             # 保存済みの株価を捨てて全銘柄を取り直す
.\run.ps1 --prices-only                # 株価だけ更新（YouTube・AIには触らない）
.\.venv\Scripts\python.exe scripts\check_captions.py   # 字幕診断
.\.venv\Scripts\python.exe scripts\check_prices.py     # 株価診断
.\.venv\Scripts\python.exe scripts\check_prices.py 7203 NVDA 日経平均   # 銘柄を指定して確認
.\.venv\Scripts\python.exe scripts\make_sample.py      # サンプルデータに戻す
```

ログは `logs\run-YYYY-MM-DD.log` に残ります（30日で自動削除）。

## 設定を変える

`scripts/config.json`

| 項目 | 意味 |
|---|---|
| `lookback_days` | 何日前までの動画を対象にするか（初期値 7） |
| `max_videos_per_channel` | 各チャンネル何本を保持・表示するか（初期値 2 = 最新と前回）。増やすほどAPI消費も増える |
| `max_videos_per_run` | 1回の実行で処理する上限（初期値 2）。1時間おき実行なので1日48本ぶんの余力があり、実際の投稿は1日3〜4本 |
| `max_transcript_attempts` | 字幕が取れなかった動画を何回まで取り直すか（初期値 8）。投稿直後は自動字幕がまだ無いこと、ライブの予約枠が後から本編になることへの対策 |
| `retain_days` | 何日分の履歴を保持するか（初期値 90）。JSONが太りすぎるのを防ぐ |
| `transcript_languages` | 字幕の優先言語 |
| `use_ytdlp_fallback` | 1つ目の方法が弾かれたとき yt-dlp で取り直すか（初期値 true） |
| `ytdlp_cookies_from_browser` | それでも弾かれるとき `firefox` を指定（ChromeはWindowsのApp-Bound暗号化で読めません）|
| `pause_seconds` | 動画1本ごとに空ける秒数（初期値 30）。YouTubeに弾かれるときは増やす |
| `block_cooldown_hours` | 弾かれたあと何時間おとなしくするか（初期値 3）。制限中に叩き続けると解除が遠のくため |
| `channels` | チャンネルの追加・削除。`slot` は 1〜4（表示色） |
| `llm.provider` | `gemini` / `openai` / `anthropic` |
| `enable_digest` | トップの「今日のポイント」を作るか（初期値 true）。要約1回ぶんのAPI利用が増えます |
| `digest_videos` | 何本の動画をまとめの材料にするか（初期値 8） |
| `enable_prices` | 株価の取得を止めたいとき `false` に |
| `price_refresh_hours` | 市場が閉まっている間に株価を取り直す間隔（初期値 12 = 実質1日1回） |
| `price_refresh_minutes_open` | 取引時間中に株価を取り直す間隔（初期値 12 分）。GitHub Actionsの15分おき実行に合わせてある |
| `profile_refresh_hours` | 価格帯別出来高を取り直す間隔（初期値 12）。通信が1回増えるので株価ほど頻繁には取りません |
| `price_pause_seconds` | 銘柄ごとに空ける秒数（初期値 2） |
| `chart_days` | チャートに載せる日足の本数（初期値 120 = 約6か月） |
| `enable_volume_profile` | 価格帯別出来高の取得。止めたいとき `false`（通信が半分になります） |
| `profile_days` | 価格帯別出来高の集計日数（初期値 5 営業日） |
| `symbol_overrides` | 銘柄名 → Yahooシンボルの手動指定。AIがコードを取り違える銘柄を直せます（例 `"キオクシア": "285A.T"`）。日本株は「コード.T」、米国株はティッカーそのまま |

**チャンネルIDの調べ方**: チャンネルページを開いてソースを表示し、`UC` で始まる24文字を探すか、
`https://www.youtube.com/@ハンドル名` を開いて「概要」→「チャンネルを共有」→「チャンネルIDをコピー」。

### AIを差し替える

`config.json` の `llm.provider` を変えて、`.env` に対応するキーを入れるだけです。

```json
"llm": { "provider": "openai", "openai_model": "gpt-4.1-mini" }
```

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| `GEMINI_API_KEY が空です` | `.env` にキーが入っているか確認。メモ帳で保存し直すとBOMが付くことがあるので、その場合は `setup.ps1` を再実行 |
| `YouTubeにアクセスを弾かれました` | 記録は残さず中断するので、時間をあけて `.\run.ps1` を再実行すれば続きから進みます。何時間も直らないときは `config.json` の `ytdlp_cookies_from_browser` に `firefox` などを設定すると、ブラウザのログイン情報を使って通るようになります（そのブラウザで一度YouTubeにログインしておくこと） |
| `この動画には字幕がありません` | その投稿者が字幕を切っています。対処法はありません（アプリ上に理由が出ます） |
| `.ps1` で「トークンを使用できません」等の構文エラー | PowerShellがファイルをShift-JISとして読んでいます。`.ps1` は**BOM付きUTF-8**で保存する必要があります。メモ帳で編集した場合は「UTF-8 (BOM付き)」を選んで保存し直してください |
| 急に全部エラーになった | YouTube側の仕様変更の可能性。`.\.venv\Scripts\python.exe -m pip install -U youtube-transcript-api` |
| アプリが古い内容のまま | 一度アプリを閉じて開き直す。それでも直らなければSafariの履歴消去 |
| PCを数日つけていなかった | 起動すれば自動で追いつきます（`lookback_days` の範囲内） |
| 更新後に「今日のポイント」がサンプル文に戻った | v22以降は起きません。もし起きたら `.\run.ps1 --digest` で作り直せます |

## YouTubeに弾かれたとき（HTTP 429）

字幕の配信エンドポイントには**IP単位のクォータ**があり、短時間に多く取ると数時間〜1日ほど429を返すようになります。
動画ページや動画情報は普通に取れるのに字幕だけ失敗する、という形で現れます。

このツールはそれを前提に作ってあります。

- 弾かれた回は**記録を残さず中断**します。再試行の回数も消費しません
- そのあと **3時間は自動でお休み**します（制限中に叩き続けると解除が遠のくため）
- お休み中も株価とアプリのデータは更新されます
- 待機が明けると、タスクスケジューラが**自動で続きから再開**します

**つまり、弾かれても何もしなくて構いません。** すぐ試したいときだけ `.\run.ps1 --force` を使ってください。

クライアント側の設定（ブラウザ偽装、Cookie、JSランタイム）では回避できません。実測で確認済みです。

## 字幕取得の仕組み（つまずいたときの参考）

YouTubeの自動字幕には2種類あります。

- `ja-orig` … 元の自動生成字幕
- `ja` … それを自動翻訳したもの

**429（Too Many Requests）が出るのは翻訳側だけ**なので、このツールは常に `<言語>-orig` を先に要求します。
それでも駄目なら順に `ja` → `en-orig` → `en` と落としていきます。

## データについて

- 株価・出来高は Yahoo Finance のチャートAPI（v8）の日足。APIキー不要・無料で、1日1回・引け後に取り直します
- **取引時間中は「現在値」を大きく表示します**（約20分遅れ。カードに「ザラ場」と出ます）。
  RSI・移動平均・出来高比などの指標は、当日の未確定バーを除いた**確定した日足だけ**で計算しています。
  カードを開くと現在値と前営業日終値の両方が確認できます
- 価格帯別出来高は同じAPIの1分足（直近5営業日）を24本の価格帯に集計したもの。分足は20分程度の遅延があります
- **歩み値（1約定ごとの約定履歴）は無料では取得できません。** 取引所が有料配信しているデータで、J-Quantsでも有料プランの領域です。
  「周りがいくらで売買しているか」を知る代わりとして価格帯別出来高を入れています
- 銘柄コードは自動変換します（日本株 `7203`→`7203.T` / 米国株 `NVDA` / 日経平均→`^N225`）
- stooq は2026年3月からAPIキー必須になったため既定では使いません。控えとして使いたい場合のみ `.env` に `STOOQ_API_KEY` を設定してください
- RSIはWilder方式の14日。終値から自前で計算しています
- **信用買残は未対応です。** JPX公式の J-Quants API は無料プランが12週間遅延で実用にならず、
  無料で新しい数字を取るにはJPXの週次公表ファイルを取り込む実装が別途必要になります。必要になったら追加します

## 注意

要約はAIが字幕から自動生成したもので、**聞き間違いや取り違えを含みます**。
特に銘柄コードや価格は誤りやすいので、判断の前に必ず「▶ 時刻から」で元動画を確認してください。
このアプリは情報整理のためのもので、投資助言ではありません。
